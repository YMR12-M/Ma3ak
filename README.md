# 🤝 معاك (MA3ak)

منصة وتطبيق لمتابعة كبار السن — تذكير بمواعيد الدواء، متابعة المواعيد الطبية، وتسجيل القياسات الصحية، مع دور خاص لمتابع (ابن/بنت/ممرض) يقدر يشوف حالة المريض أول بأول.

## الأدوات المستخدمة (زي ما اتفقنا)

| # | التقنية | الاستخدام |
|---|---------|-----------|
| 1 | HTML | `frontend/index.html` — نقطة الدخول الوحيدة للصفحة |
| 2 | CSS | `tokens.css` + `global.css` — الألوان والتنسيق |
| 3 | JavaScript | كل منطق الفرونت إند (React بدون build tool) والباك إند (Express) |
| 4 | JSON | كل رد من الـ API، وتخزين مواعيد الدواء (`times`) في قاعدة البيانات |
| 5 | Node.js | بيئة تشغيل الباك إند |
| 6 | Express | الـ REST API |
| 7 | MySQL | تخزين المستخدمين، المرضى، الأدوية، الجرعات، المواعيد، القياسات، الإشعارات |
| 8 | React | واجهة المستخدم (محمّلة عبر CDN + Babel Standalone — بدون npm/webpack/vite) |

السيرفر (Express) هو اللي بيسِرف ملفات الفرونت إند نفسها، يعني سيرفر واحد بس (`node server.js`) وبتفتح المتصفح على نفس البورت.

## هيكل المشروع

```
ma3ak/
  frontend/
    index.html
    css/
      tokens.css       # الألوان والمقاسات (Design Tokens)
      global.css        # كل التنسيق
    js/
      api.js             # التواصل مع الـ API
      components/        # كل مكونات React (ملفات .jsx، بيتترجموا لايف في المتصفح بـ Babel)
      app.jsx             # نقطة انطلاق React
  backend/
    server.js            # نقطة انطلاق Express
    db.js                # اتصال MySQL
    scheduler.js         # توليد الجرعات + إشعارات الفوات والمواعيد القريبة
    middleware/auth.js   # التحقق من JWT
    utils/access.js      # التحقق من صلاحية الوصول لمريض معين
    routes/               # auth, patients, medications, doses, appointments, vitals, notifications
    sql/schema.sql        # قاعدة البيانات
    .env.example
    package.json
```

## 1) تثبيت MySQL (macOS)

لو معندكش MySQL متثبت:

```bash
brew install mysql
brew services start mysql
```

بعد التثبيت، MySQL بيشتغل بحساب `root` بدون باسورد افتراضيًا على أول تثبيت. لو حابب تحط باسورد:

```bash
mysql_secure_installation
```

## 2) إنشاء قاعدة البيانات

```bash
cd "backend"
mysql -u root -p < sql/schema.sql
```

(لو مفيش باسورد على root، امسح `-p`)

ده هيعمل قاعدة بيانات اسمها `ma3ak` بكل الجداول المطلوبة.

## 3) إعداد متغيرات البيئة

```bash
cd backend
cp .env.example .env
```

افتح `.env` واملأ بيانات الاتصال بتاعتك (`DB_USER`, `DB_PASSWORD`, ...) وغيّر `JWT_SECRET` لأي نص عشوائي طويل.

## 4) تثبيت المكتبات وتشغيل السيرفر

```bash
cd backend
npm install
npm start
```

هتلاقي في الترمينال:

```
🤝 MA3ak server running on http://localhost:3000
```

افتح المتصفح على `http://localhost:3000` — دي نفس الصفحة اللي فيها الفرونت إند والباك إند بيشتغلوا مع بعض.

## إزاي تستخدم التطبيق

المريض (كبير السن) **مش بيسجل بنفسه خالص** — المتابع (الابن/البنت/الممرض) هو اللي بيعمل كل حاجة:

1. المتابع بيعمل حساب لنفسه: الاسم + **رقم الموبايل (إجباري)** + إيميل (اختياري) + باسورد.
2. من تاب "المرضى"، المتابع بيدوس "➕ إضافة مريض جديد" ويكتب اسم المريض (ورقم موبايله لو حابب).
3. التطبيق بيطلّع **لينك دخول** واحد للمريض ده — المتابع بينسخه ويبعته للمريض على واتساب.
4. المريض بس بيدوس على اللينك من على موبايله → بيدخل التطبيق على طول، من غير تسجيل ولا باسورد ولا أي خطوة تانية.
5. المتابع بيجهّز كل حاجة قبل كده: الأدوية بمواعيدها، المواعيد الطبية، القياسات الصحية — المريض هيلاقيها جاهزة، ومطلوب منه بس إنه يدوس "✅ اتاخد" لما ياخد الدوا.
6. لو عايز متابع تاني (زي أخته مثلًا) ينضم لمتابعة نفس المريض، يقدر ياخد "كود المشاركة" (6 حروف) من كارت المريض ويدخله من "عندك كود مشاركة؟" تحت تاب "المرضى".
7. لو الجرعة عدى ميعادها بـ 30 دقيقة من غير تسجيل، بتتحول "فايتة" تلقائيًا ويوصل إشعار للمريض وكل المتابعين، وده بيحصل عن طريق سكريبت (`scheduler.js`) بيشتغل كل 5 دقايق جوه السيرفر نفسه.

### ملاحظة أمان مهمة

لينك دخول المريض بيدّي دخول كامل لحسابه من غير باسورد — يعني أي حد يفتح اللينك ده يقدر يشوف بياناته. ابعته للمريض بس عن طريق قناة موثوقة (واتساب شخصي مثلاً)، ولو حسيت إنه اتسرب دوس "🔄 لينك جديد" من كارت المريض عشان تلغي القديم فورًا.

## ملاحظات

- الفرونت إند مبني بـ React عن طريق CDN (`unpkg.com`) + Babel Standalone بيترجم JSX جوه المتصفح — من غير أي خطوة `build`، عشان ده كان مطلوب. الاعتماد على الإنترنت مطلوب أول مرة بس عشان تحميل السكريبتات (المتصفح بيكاشيهم بعد كده).
- تسجيل الدخول عن طريق JWT مخزّن في `localStorage`.
- الإشعارات جوه التطبيق تظهر في تاب "الإشعارات"، وكمان ممكن تظهر كـ Notification من المتصفح لو سمحت بالصلاحية.
