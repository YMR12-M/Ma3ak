# 🤝 معاك (MA3ak)

منصة وتطبيق لمتابعة كبار السن — منبه بمواعيد الدواء بيوصل والتطبيق مقفول، متابعة المواعيد الطبية، وتسجيل القياسات الصحية، مع دور خاص لمتابع (ابن/بنت/ممرض) يقدر يشوف حالة المريض أول بأول.

المنبه مش إشعار بيتبعت مرة: الجرعة حالة بتتصعّد — منبه للمريض بزرار "خدته" شغّال من جوّه الإشعار، تذكير تاني، تنبيه للمتابع لو فاتت، وتصعيد لو المريض مردّش خالص.

## التشغيل

المشروع بيشتغل محليًا بخطوات معدودة — التفاصيل الكاملة في [docs/SETUP.md](docs/SETUP.md)،
وخطوات النشر على Render في [docs/DEPLOY.md](docs/DEPLOY.md).
