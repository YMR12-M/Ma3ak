# توثيق معاك (MA3ak)

فهرس التوثيق التقني للمشروع. الـ README الرئيسي في جذر المشروع بيقدّم المشروع بسرعة (وصف + لينك تجربة + تقنيات)؛ هنا التفاصيل.

- **[ARCHITECTURE.md](ARCHITECTURE.md)** - البنية العامة: إزاي الفرونت إند والباك إند شغالين مع بعض، هيكل المجلدات، وأهم قرارات التصميم وليه اتاخدت.
- **[API.md](API.md)** - كل الـ endpoints في الباك إند: الميثود، المسار، الصلاحيات المطلوبة، شكل الطلب والرد.
- **[DATABASE.md](DATABASE.md)** - شرح جداول قاعدة البيانات والعلاقات بينها.
- **[SETUP.md](SETUP.md)** - إزاي تشغّل المشروع كامل على جهازك من الصفر.
- **[DEPLOY.md](DEPLOY.md)** - إزاي تنشر المشروع على Render (قاعدة البيانات، الإعدادات، والقيود).
- **[FEATURES.md](FEATURES.md)** - كل ميزة في التطبيق من ناحية المستخدم (متابع ومريض)، وأهم القيود المعروفة حاليًا.
- **[DESIGN.md](DESIGN.md)** - نظام التصميم: طبقات الـ CSS، متغيرات التصميم، قواعد الحركة والإتاحة، وإزاي تضيف مكوّن جديد.

## المشروع باختصار

معاك منصة لمتابعة كبار السن: تذكير بمواعيد الدواء، متابعة مواعيد طبية، وتسجيل قياسات صحية، مع دور "متابع" (ابن/بنت/ممرض) بيقدر يشوف حالة المريض. المريض بيستخدم شاشة مبسطة بلينك دخول من غير باسورد؛ المتابع بيستخدم لوحة تحكم كاملة.
