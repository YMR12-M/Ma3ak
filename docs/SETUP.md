# تشغيل المشروع محليًا

## المتطلبات

- Node.js 18+ (السيرفر بيستخدم `node --watch` للتطوير، متاح من Node 18.11)
- MySQL 8+ (شغّال ومتاح على الجهاز)

مفيش أي متطلبات تانية. الفرونت إند ليه خطوة بناء واحدة (esbuild، بتتسطّب مع `npm install`)،
لكن **ناتج البناء متسجّل في الريبو** - يعني `npm start` بيشتغل على نسخة جديدة من غير ما تبني أي حاجة.
محتاج تبني بس لو عدّلت في `frontend/js/` أو `frontend/css/`.

## الخطوات

### ١. قاعدة البيانات

```bash
cd backend
mysql -u root -p < sql/schema.sql
```

ده بيعمل قاعدة `ma3ak` كاملة (الأمر نفسه بيعمل `CREATE DATABASE IF NOT EXISTS`، مش لازم تعملها إنت الأول). **متشغّلش ملفات `migration_*.sql`** بعد كده - دي لترقية قاعدة قديمة بس، والـ schema الحالي فيها كل حاجة مدموجة بالفعل (تفاصيل في [DATABASE.md](DATABASE.md)).

### ٢. متغيرات البيئة

```bash
cp .env.example .env
```

افتح `.env` واتأكد من بيانات الاتصال بقاعدة البيانات (`DB_HOST`, `DB_USER`, `DB_PASSWORD`, `DB_NAME`)، وغيّر `JWT_SECRET` - السيرفر بيرفض يشتغل لو قصير أو غير موجود (16 حرف على الأقل). تقدر تولّد واحد عشوائي بالأمر:

```bash
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
```

### ٣. تثبيت الحزم وتشغيل السيرفر

```bash
npm install
npm run dev     # بناء الواجهة + node --watch - بيعيد تشغيل السيرفر عند أي تعديل
# أو
npm start       # تشغيل عادي (بيستخدم ناتج البناء المتسجّل في الريبو)
```

لو هتشتغل على الواجهة نفسها، شغّل البناء في وضع المتابعة في تيرمينال تاني عشان يعيد
البناء مع كل حفظ:

```bash
npm run build:watch
```

ولو عدّلت في `frontend/js/` أو `frontend/css/`، **لازم تشغّل `npm run build` وتسجّل ناتج
`frontend/dist/` مع التعديل** - فيه فحص في CI بيتأكد من ده. التفاصيل في
[ARCHITECTURE.md](ARCHITECTURE.md#خطوة-البناء-build).

السيرفر بيشتغل على `http://localhost:3000` بشكل افتراضي (أو `PORT` من `.env`). ده بيعمل حاجتين مع بعض:
- بيسيرف الفرونت إند كامل (`frontend/` كملفات استاتيك).
- بيشغّل الـ scheduler (توليد الجرعات، تذكير المواعيد) في الخلفية كل 5 دقايق.

**متبقاش مبعوت لازم تشغّل حاجة تانية للفرونت إند** - افتح `http://localhost:3000` في المتصفح وخلاص.

## تجربة سريعة بعد التشغيل

1. افتح `http://localhost:3000` → بوب "حساب جديد" → سجّل كمتابع (اسم + موبايل + باسورد).
2. من تاب "المرضى" → "إضافة مريض جديد" → هيديك لينك دخول (`access_token`) وكود مشاركة (`link_code`).
3. افتح اللينك في تاب تصفح تاني (أو نافذة خاصة) - هتدخل كشاشة المريض على طول بدون أي تسجيل دخول.
4. من شاشة المتابع، ضيف دواء بميعاد قريب من الوقت الحالي، وهتلاقي زرار "خدت الدوا" بيفتح لوحده في شاشة المريض.

## تشغيل الاختبارات

اختبارات المنطق الحرج (صلاحيات الوصول، توقيت الجرعات، بوابة الـ JWT) بتشتغل بـ `node --test` المدمج في Node - مش محتاجة تثبيت أي حاجة إضافية ولا قاعدة بيانات شغالة:

```bash
cd backend
npm test          # اختبارات الباك إند بس (backend/test/)
npm run test:all  # الباك إند + الفرونت إند مع بعض (frontend/test/)
```

## مشاكل شائعة

- **"JWT_SECRET مش موجود أو قصير"**: السيرفر بيرفض يبدأ عمدًا - راجع الخطوة ٢.
- **`ECONNREFUSED` من MySQL**: اتأكد إن MySQL شغّال (`mysqladmin ping -u root`) وإن بيانات `.env` مطابقة.
- **`EADDRINUSE` على البورت**: فيه سيرفر تاني شغّال على نفس البورت (`lsof -i :3000` عشان تعرف مين وتقفله).
